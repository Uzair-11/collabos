CollabOS Logo System
=====================

Files included:

PRIMARY LOCKUP (icon + wordmark, for website header / decks / email signatures)
- primary-lockup-light.svg   - full color, for light/parchment backgrounds
- primary-lockup-dark.svg    - reversed, for pine/dark backgrounds

STACKED LOCKUP (icon above wordmark, for square placements)
- stacked-lockup-light.svg   - light background
- stacked-lockup-dark.svg    - reversed, dark background

ICON / APP ICON (mark only)
- icon-badge.svg             - badge icon, light background, for avatars/favicons at medium size
- icon-badge-reversed.svg    - badge icon, dark background
- app-icon.svg                - 512x512, squircle, iOS/Android app icon (no transparency)
- favicon.svg                 - flat 48x48 favicon, simplified for small sizes (use below 48px)

WORDMARK ONLY (for footers, co-branding, legal text)
- wordmark-light.svg
- wordmark-dark.svg

MONOCHROME (single-color use: invoices, stamps, print, apparel)
- monochrome-black.svg        - black outline on white
- monochrome-white.svg        - white outline on dark
- watermark.svg                - 15% opacity, for contract/document backgrounds

USAGE NOTES
- Fonts: wordmark and monogram use "Baloo 2" (Google Fonts). If opening these
  SVGs outside a browser with internet access, they'll fall back to your
  system's default bold sans-serif.
- Minimum size: don't use the badge/ring icon below 48px — switch to favicon.svg
  instead, since the ring detail disappears at small sizes.
- Clear space: keep padding around the mark roughly equal to the height of
  the "C" monogram.
- Colors: Pine #1F3D2E, Clay #C1622E, Parchment #F6F0E4, Slate ink #2B2B28.
